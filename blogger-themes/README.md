# Nationalist Academy Blogger theme

The Nationalist Academy Blogger theme is maintained in [theme.xml](./theme.xml) for [nationalistacademy.blogspot.com](https://nationalistacademy.blogspot.com/).

This is a **Nationalist Academy-branded customization of the Lantro UI v1.5 upstream theme**, not a claim that the upstream theme was originally authored by Nationalist Academy. The original STW Team / Somadan Media attribution and upstream licence notice are retained. Use it only if the account has the required valid theme licence.

## Nationalist Academy changes

- Nationalist Academy site branding, navigation, search labels and homepage topic cards.
- Responsive desktop/mobile layout, existing Lantro UI widgets, dark mode and Blogger post rendering retained.
- Teal/navy brand palette and responsive legal footer.
- Proprietor and business-status disclosure: sole proprietorship, Faiez Mehmood, Karachi, Pakistan, and official contact email.
- NTN status disclosed as registered as stated by the proprietor; no NTN number is published in the theme.
- Clear statement that Nationalist Academy is not an incorporated company, NGO, charity, university, government body, law firm or regulatory authority.
- OSINT/public-source research section with source URLs, access dates, corroboration, uncertainty and privacy safeguards.
- SEO description fallbacks, social metadata and Organization/WebSite structured data.
- No links to Assignmentwaly, AIOU Coaching or TaleemWaly.

## Licensing and public repository safety

- The upstream Lantro UI source attribution and purchase/licence link are intentionally preserved.
- The XML still contains the upstream placeholder \`your_license_key_here\`. It is **not** a valid licence.
- Do not publish the theme as a licensed installation until the upstream licence is verified and any required key is applied by an authorized licence holder.
- Do not commit a real licence key to this public GitHub repository. If the upstream provider requires a key in the template, apply it privately in the Blogger dashboard after downloading the repository file.
- Do not remove upstream credits or licence notices.

## Legal and OSINT boundaries

The footer identifies the proprietor and operating model and includes an informational disclaimer. OSINT content is limited to lawfully accessible public sources and educational source-verification methods. It must not facilitate account intrusion, doxxing, stalking, harassment, covert tracking, unauthorized access or disclosure of sensitive personal data.

The theme is not a substitute for full Privacy, Terms, Copyright, Complaints, Corrections and other policy pages. A check of the public Blogger pages feed on 1 November 2026 returned zero published static pages, and common About/Privacy/Terms/Contact page URLs returned 404. The theme does not create Blogger pages. If those pages have been created as drafts, publish them in Blogger and add them to the Page List; otherwise create them before relying on separate policy-page links.

## Install safely

1. Open the **Nationalist Academy** Blogger dashboard only.
2. Back up the current theme using **Theme → Backup**.
3. Confirm the upstream Lantro UI licence and terms before installing.
4. Upload the reviewed XML using **Theme → Restore**.
5. Preview desktop and mobile, then check navigation, search, posts, comments, labels, page list, cookie notice, widgets and any advertising units.
6. Publish only after the live preview and licence checks pass.

Updating this GitHub repository does **not** install or publish the theme on Blogger. This theme is only for Nationalist Academy and must not be installed on other blogs without separate permission and adaptation.

AdSense IDs are not embedded. Configure advertising only through the blog's verified AdSense account and Blogger settings. No theme can guarantee AdSense approval, rankings or revenue.
