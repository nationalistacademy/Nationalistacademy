# Nationalist Academy Blogger theme

The original Blogger theme for the **Nationalist Academy** blog is maintained here:

- Theme file: [`theme.xml`](./theme.xml)
- Intended blog: [nationalistacademy.blogspot.com](https://nationalistacademy.blogspot.com/)

This theme is purpose-built for Nationalist Academy. It is not a shared theme for the other independent blogs in the wider project network.

## Included

- Original responsive desktop and mobile layout.
- Nationalist Academy branding, mission-led homepage and project cards.
- Mobile bottom navigation: Home, Search, Projects and Top.
- Responsive collapsible mobile menu.
- Dark mode with local preference.
- Blogger-native Blog, Popular Posts and Labels widgets.
- Blogger search form and canonical/meta description support.
- Open Graph basics, accessible labels, skip link and reduced-motion support.
- Footer links for organization contact and policy information.
- No premium Lantro UI code, third-party theme scripts, or TaleemWaly links.

## Install safely

1. Open the **Nationalist Academy** Blogger dashboard.
2. Go to **Theme → Backup** and download the current theme.
3. Use **Theme → Restore** to upload `theme.xml`, or use **Edit HTML** if you know how to replace the complete template safely.
4. Preview the theme on desktop and mobile before publishing.
5. Check Layout, posts, static pages, search, comments, labels, analytics and any advertising units after installation.

The XML file is stored in GitHub only. Updating this repository does **not** install or publish the theme on Blogger. Do not install this Nationalist Academy theme on Assignmentwaly or AIOU Coaching without a separate adaptation and review.

AdSense IDs are intentionally not embedded. Configure advertising only through the relevant blog's verified AdSense account and Blogger settings. The theme does not guarantee AdSense approval, search rankings or revenue.
