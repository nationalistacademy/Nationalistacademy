# Blogger theme

## Unified learning-network theme

File: `nationalist-academy-unified.xml`

This is a reusable, responsive Blogger XML theme for the Nationalist Academy blog network. It uses the active Blogger blog's title and homepage URL automatically and provides cross-navigation to:

- [TaleemWaly](https://taleemwaly.blogspot.com/)
- [Assignmentwaly](https://assignmentwaly.blogspot.com/)
- [AIOU Coaching](https://aioucoaching.blogspot.com/)
- [Nationalist Academy](https://nationalistacademy.blogspot.com/)

### Included
- Responsive desktop and mobile layouts.
- Sticky header and mobile bottom navigation.
- Blogger-native Blog, Popular Posts and Labels widgets.
- Built-in Blogger search form.
- Optional dark mode with local preference.
- Semantic headings, canonical homepage URL and meta description.
- Reduced-motion support and keyboard skip link.

### Install safely
1. Open the target Blogger dashboard.
2. Go to **Theme → Backup** and download the current theme first.
3. Choose **Edit HTML** or **Restore** and upload/paste this XML.
4. Preview desktop and mobile before publishing.
5. Check Layout, labels, comments, search, ads and all important pages after installation.

The theme file is a reusable starting point, not a live Blogger deployment. It does not change any blog until an administrator installs it. AdSense publisher/slot IDs are intentionally not hard-coded; configure ad units through the target blog's verified AdSense setup.
